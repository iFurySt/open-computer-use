# v1.1.3 发布执行计划

## 目标与范围

按 RELEASE_GUIDE 从最新 main 发布补丁版本 1.1.3，统一版本源、验证签名制品，并确认 GitHub Release 与三个 npm 包公开可用。用户已明确授权公开发布；不修改系统 Locked Use 安装或锁屏状态。

## 风险与验证

- 版本或制品错配：校验英文 notes、Swift / Go / plugin 版本、npm staging、universal App、DMG、直接下载归档及 SHA256SUMS。
- 签名 / 公证或 npm 认证失败：跟踪 release workflow，检查失败日志，保留已发布版本。
- registry 缓存传播：核对 dist-tags 和普通 npm view，不因短暂 404 重发。
- 运行 swift test、仓库 CI、Go CLI 测试；发布后比较 Release 正文与仓库 notes，验证下载资产和公证票据。
