# PR #143：独占 HID 兼容与接管监控

## 目标

修复 #142 的独占设备启动失败，同时避免仅剩一个无关输入设备也被误判为健康。保持 Guardian 与 watchdog 的接管、故障停止和释放边界。

## 调查与设计

- 本机未安装 / 运行 Karabiner，不能声称本机完整复现该环境。
- 原 PR 的 manager 与设备生命周期混用；按 Apple SDK 的 independent-devices 模式枚举并逐个管理打开、回调与清理。
- 只允许跳过 exclusive-access；其他错误仍失败。所有出现的输入类别必须有可观察来源，不能用消费按键设备代替键盘 / 指针。
- 新增设备、设备移除、输入错误使当前监控失效，不在运行中的租约里悄悄扩大或缩小覆盖。
- 通过可注入 IOKit 后端测试真实 monitor 的状态和清理；本机实际设备验证普通监听。Karabiner 的转发与 Secure Input 需要独立实测，不用合成输入冒充真人接管。
