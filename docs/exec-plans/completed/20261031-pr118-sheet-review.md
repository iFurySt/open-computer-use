# PR #118：focused sheet 快照与输入一致性

## 目标与范围

基于最新 main 复核 #118，保留贡献者提交，修复合并冲突及与 #127 的交叉问题，推送原 PR 分支。macOS 的 sheet 应成为 AX、截图、查询与元素动作的共同目标；不扩展原始事件跨 XPC 输入。

## 风险与验证

- sheet 根索引不能触发内部按钮；沿用窗口索引的激活回退，失败不得改点内容。
- query 的窗口回查应接受仍存在的 focused sheet，关闭后旧索引必须失效。
- 使用临时 AppKit fixture，覆盖普通及过滤父窗口 AXChildren 的 NSOpenPanel、独立模态面板、截图缩放、AX-only、Cancel 的快照/查询/坐标点击。
- 使用正常签名的独立输出制品和现有权限；不替换安装、不改授权、不开物理指针兜底。测试不断言活跃桌面的前台/指针稳定性。
- 默认虚拟显示器关闭；本轮不为测试改变显示器布局。
- 跑 Swift 全套，并用修复前制品做负对照。

## 实测发现

- 原 PR + 最新 main：自定义 sheet 根索引会按下 Cancel，已用真实 receiver 复现；根索引改走 Raise/focus。
- 自定义 sheet 的控件 AXWindow 指向父文档，原归属检查拒绝 query 点击；保留有界父链检查。
- query 的 50–100 ms 读取超时会残留到动作（system-wide 对象还会修改进程全局超时）。实测 Cancel 已关闭弹窗却返回失败；只读解析结束和动作前恢复默认超时，fixture 用 150 ms 回调验证。
- main 的负对照仍以父窗口为目标，未选中当前面板；新实现通过同一脚本。

- 最终真实面板矩阵 12/12 通过，默认节点/深度/超时预算未放宽。深层临时目录列视图超过 30 秒，合并前 main 的独立模态面板也复现，记入技术债，留给 AX 遍历优化。
