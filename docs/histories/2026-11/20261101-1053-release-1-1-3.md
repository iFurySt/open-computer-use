# v1.1.3 release

## 用户诉求

main 分支按照发版 SOP 发一个小版本，确认采用补丁版 1.1.3。

## 改动与设计

- 从最新 main 同步 plugin、Swift / Go runtime、smoke、测试和 CLI 示例的版本至 1.1.3。
- 新增审核版英文 Release notes 和用户发布记录，覆盖 v1.1.2 以来的 macOS 输入 / 观察修复、跨平台按需观察、Windows / Linux 优化及 Locked Use 公证票据打包修复。
- 沿用既有 npm 包名、CLI 别名与签名身份；使用既有 release workflow 发布。

## 验证与发布

- Swift：419 项，9 项跳过、0 失败；包含真实 AX 光标跟随回归。
- Node：54 项通过；Linux Python：35 项通过；Locked Use 诊断 / 公证 / 真实打包模拟测试：8 项通过。
- Windows runtime 与 Go CLI 单测通过；Linux Go 测试在 macOS 上被平台守卫拒绝，交叉编译后在隔离 Linux 容器中全部通过。
- 文档骨架与 Actions SHA 检查通过。仓库总 CI 的 hygiene 步骤因 main 已缺少 11 个旧模板文件而失败（包括 `.editorconfig`、PR / Issue 模板、旧 CI workflow 与 markdownlint 配置）；未将这项既有问题记为通过，其余检查单独执行。
- Developer ID universal App 与四个 Locked Use 组件签名 / 架构检查通过，插件 ABI 和 kernel verifier 正负例通过；三个 npm staging 包均为 1.1.3，含全部 runtime、ocu alias，无 optionalDependencies，嵌套 bundle 版本和签名一致。
- CursorMotion-1.1.3.dmg 构建、universal 架构、签名与镜像校验通过；macOS App、四个 CLI、skill 直接下载包及 manifest / SHA256SUMS 检查通过。
- 本机 Bash 3.2 在未设置 keychain 时触发空数组错误，改用已有 Bash 5 后签名构建完成；已在发版指南补充处理方法。签名 keychain 选择与恢复回归通过。
- 公开发布待执行。
