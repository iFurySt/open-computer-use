# v1.1.6 patch release

The maintainer requested a patch release after merging #199. Based on main,
this release includes Locked Use recovery when all recorded processes exit
before authorization, macOS text-field and outline click fixes, the Date
interval fix, and Homebrew documentation.

The Broker regression exercises production polling through injected exit
observations. No real lock screen or installed service is used for release
packaging verification. See [execution plan](../../exec-plans/active/20261123-release-1.1.6.md).

The v1.1.5 legacy npm alias is now available. Its registry tarball SHA-512,
runtime files, strict app signature, and nested notarization tickets passed.
This resolves the previous release's registry visibility follow-up.

Swift passed 510 tests (14 skipped). The release notes, repository checks,
three staged packages, signed universal app and all four Locked Use components
passed. The packaged native executable reports 1.1.6 and passes MCP stdio
notification smoke. The DMG, four native Linux/Windows archives, and public
asset staging checksums also passed.

Xcode 27.2 reproduced a lipo failure when checking two architectures at once.
The release build now checks each requested slice separately. A real universal
artifact passed both checks and a thin ARM artifact correctly failed its
x86_64 check. All signing and notarization requirements remain in place.
