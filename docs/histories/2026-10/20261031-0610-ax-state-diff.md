# Opt-in lossless AX state diffs in the JS REPL

Date: 2026-10-31

Request (condensed): let an agent that rereads the same window get only what changed,
without losing any line, and keep full text as the default.

- Added `scripts/node-repl/ax-state-diff.mjs`. `AXStateDiff` splits a tree into
  element lines (keyed by their leading index) and non-element lines. The first read
  returns `ax-full` with a revision and the complete text; later reads return
  `ax-diff` with `baseRevision`, `revision`, `added` / `changed` element lines,
  `removed` indexes and, when the order changed, a `layout` array.
  `applyAXStateDiff` rebuilds the exact text and rejects a revision gap.
- `app.getAXState({ diff: true })` opts in; `disableDiffing: true` forces full text.
  Each app binding has its own baseline. A changed App/Window header, changed
  observation options, native errors, duplicate indexes, screenshot reads and calls
  without `diff` reset it. `diff` / `disableDiffing` are validated as booleans and are
  not forwarded to the native tool.
- Packaged the new module with the npm package, the bundled plugin copy and
  `scripts/install-codex-plugin.sh`. `ocu capabilities` now reports the JS/REPL
  adapter as unavailable when a module it imports is missing.
- Documented the packet format in `docs/references/js-repl.md`, the REPL
  instructions and `docs/ARCHITECTURE.md`.

Why: agents often read the same window again after a small action. A full tree of a
large chat-app window is about 45,000 characters; an unchanged reread as a diff is an
85-character packet. The native AX walk still runs in full, so this saves model input,
not read time.

Validation: unit tests cover additions, removals, reordering, indentation, focus and
selection lines, unchanged reads, resets, duplicate indexes, a missed packet and 200
deterministic mixed snapshots reconstructed byte for byte; an API test covers the
default, scoping, `disableDiffing`, error reset and argument validation. Six real
snapshots of two live windows were also reconstructed exactly during development.
All 56 Node tests in `scripts/node-repl/` and the 4 tests in `scripts/tests/` passed.
No Swift source changed; the full Swift suite still executed 399 tests with 8 skipped
and 0 failures. `make check-docs` passed. `scripts/check-repo-hygiene.sh` reports
files that are already absent on the base branch.
